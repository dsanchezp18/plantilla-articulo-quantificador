# Aviso sobre datos

Este repositorio puede incluir o descargar datos publicados originalmente por
terceros. LIDE no es titular de esos datos y no los licencia. Cada fuente
mantiene sus propios términos de uso, citación y redistribución. Consulta
`documentation/fuentes.csv` y el sitio de cada institución antes de
reutilizarlos.

Los datos crudos no se versionan en este repositorio: `data/raw/` se llena con
`code/cleaning/00_download_fuente.R`. Las ofertas laborales, textos de redes
sociales y cualquier contenido de terceros con derechos propios tampoco se
publican.

Lo que Laboratorio de Investigación para el Desarrollo del Ecuador sí produce, como las tablas derivadas de
`outputs/tables/` y las figuras, se distribuye bajo CC BY-NC 4.0 según
`LICENSE-content`.

Si eres titular de alguno de estos datos y quieres que lo retiremos, escríbenos
a elquantificador@laboratoriolide.org.
